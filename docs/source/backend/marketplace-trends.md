# Marketplace Trends

## Purpose

Track local Facebook Marketplace asking-price trends.

## Important Note

Marketplace prices are asking prices, not confirmed sale prices.

## Metrics

Track:
- median asking price
- 25th percentile asking price
- 75th percentile asking price
- active listing count
- new listing count
- disappeared listing count
- price drop frequency
- average days visible
- median mileage for vehicle searches

## Group Trends By

- category
- search profile
- queryKey
- locationRegion
- parsed attributes

## Example Segments

Vehicle:
- Bay Area Civic Si manual clean title
- Bay Area Miata manual
- Toyota Tacoma 4x4

Office chair:
- Berkeley Herman Miller Aeron size B
- Steelcase Leap V2

Wheels:
- 5x114.3 18-inch wheels

## Trend Output

Trend service should output:
- sample size
- median price
- price range
- listing count
- confidence level
