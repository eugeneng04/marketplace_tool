# UI Overview

## Goal

The UI should help the user quickly search, filter, compare, save, reject, and evaluate Marketplace listings.

## Main Screens

- Dashboard
- Search Profiles
- Listings
- Listing Detail
- Market Trends
- Settings

## UI Style

The design should be:
- desktop-first
- clean
- information-dense
- easy to scan
- filter-heavy
- similar to a mix of Marketplace, Airtable, and an automotive search dashboard

## Navigation

Use a left sidebar with these sections:
- Dashboard
- Search Profiles
- Listings
- Saved
- Market Trends
- Settings

## Important UI Elements

- listing cards
- listing table rows
- filter sidebar
- search profile cards
- deal score badges
- status badges
- risk flag badges
- modification badges
- parsed attribute tables
- price history cards
