# Frontend Pages

## Dashboard

### Purpose

Show a summary of recent activity and important listing updates.

### Content

- new listings today
- saved listings
- price drops
- possibly gone listings
- best deal score
- recent search runs
- high-score listings
- market trend summary

## Search Profiles

### Purpose

Let users create and manage saved searches.

### Content

Each search profile should show:
- name
- category
- query
- location
- radius
- filters
- last run
- new listings found
- enabled or paused state

### Actions

- create profile
- edit profile
- run now
- pause
- delete
- view results

## Listings

### Purpose

Main page for browsing cached listings.

### Layout

- left filter sidebar
- top search and sort bar
- main listing table or card grid

### Filters

- category
- price range
- mileage max
- transmission
- title status
- color
- location
- status
- first seen
- last seen
- deal score

### Sort Options

- deal score
- price
- mileage
- first seen
- last seen
- price drop

## Listing Detail

### Purpose

Show all information about one listing.

### Content

- image gallery
- title
- price
- location
- source link
- status controls
- deal score
- parsed attributes
- detected modifications
- risk flags
- parser evidence
- price history
- local market comparison
- raw description
- notes

## Market Trends

### Purpose

Show Marketplace asking-price trends by area and item segment.

### Content

- median asking price
- 25th percentile price
- 75th percentile price
- active listing count
- disappeared listing count
- price drop frequency
- mileage buckets for vehicles
- clean vs salvage comparison
- manual vs automatic comparison

## Settings

### Purpose

Configure app behavior.

### Content

- default location
- refresh preferences
- parser preferences
- source settings
- category settings
